# Lorch Update Center Agent – Updatekanal

Dieses Repository enthält ausschließlich die öffentlich abrufbaren
Release-Artefakte des Lorch Update Center Agents:

- Joomla-Updatefeed
- XML-Änderungsprotokoll
- signierte beziehungsweise per SHA256 geprüfte Release-Pakete

Der Anwendungscode und vertrauliche Betriebsdaten des Lorch Update Centers
sind nicht Bestandteil dieses Repositorys.
